# TurSupport

Landing page bilingüe PT-BR / ES para TurSupport.

## Servicios
- Atendimento bilíngue em português e espanhol
- WhatsApp, Booking, Airbnb, Instagram, Facebook e e-mail
- Gestão e acompanhamento de reservas
- Suporte operacional
- Automação e IA

Site estático com `index.html`, compatível com Vercel.
